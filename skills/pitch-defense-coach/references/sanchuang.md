# 三创赛：电商价值、三创区分与实战证据

用户参加全国大学生电子商务“创新、创意及创业”挑战赛时读取本文件。不能与“挑战杯”混用。先核对届次、常规赛/具体实战赛、小组赛/终极赛、当地通知和材料版本。只有PPT也可开练；题库是可选材料。

## 规则基线（2026-11-19核验）

来源：[第17届竞赛规则，组委会文件](https://sanchuang-bodao.oss-cn-hangzhou.aliyuncs.com/system/2026-11-03/2117518848162500608_20261028%20%20%20%E7%AC%AC17%E5%B1%8A%E4%B8%89%E5%88%9B%E8%B5%9B%E7%AB%9E%E8%B5%9B%E8%A7%84%E5%88%99.pdf)，重点为规则速览、现场答辩规定与附录三；[高校转载的组委会规则](https://jwb.bnuzh.edu.cn/docs/2026-11/f5baa6537037495b95bf8080cdcaca9d.pdf)。新届次重新核验，不把网页上传年份当参赛年份。

- 常规赛参考权重：创新25、创意25、创业25、演讲15、文案10。
- 实战赛参考权重：创新15、创意15、创业准备10、创业过程20、创业成绩15、演讲15、文案10。具体业绩口径还须读相应实战赛指南，不能用常规赛或其他专项代替。
- 小组赛：路演不超过8分钟，问答7分钟；终极赛一般只路演8分钟。终极赛后追加问答须称“加练”，不可称官方环节。

以上用于配置训练，反馈给证据充分度，不预测官方得分。缺少《项目报告书》时，文案维度注明仅评已提供的PPT/讲稿；未观察到的团队协作、现场动作不得补评。

## 选模式并保存本轮口径

网页赛事模式选择 `sanchuang-regular` 或 `sanchuang-practical`；二者预置8分钟路演和7分钟答辩，**不会自动勾选串联**。小组赛需要串联时由用户选择；终极赛保持单独路演。仍可单练答辩或不计时专项。时长可按已核实通知调整。

实例也可在 `public/knowledge.json` 设 `competitionProfile` 为对应ID，作为新轮次默认值。`project` 保留原项目自定义维度。每轮冻结 `competition` 和 `ruleWeights`；`dimension`、报告 `dimensions[].name` 按本轮配置填写，常规赛5项、实战赛7项，不再强凑国创赛4项。串联沿用路演冻结的赛事配置。历史记录不改。

答辩时间仍是工具的有效训练时间：等待教练、转写及人工暂停不计入；并非真实赛场全程连续7分钟。路演为连续计时。复盘分别报告这两种口径。

## 三个“创”要能分清

| 维度 | 教练要听到什么 | 有针对性的追问 |
| --- | --- | --- |
| 创新 | 相对现有产品、技术、服务或模式的具体改变，以及改变带来的验证结果 | 如果去掉你们这一改动，客户的哪个问题会重新出现？ |
| 创意 | 怎样把改变组织成可行的业务、营销、交付与财务方案 | 第一笔交易怎样完成，哪个环节由你们负责？ |
| 创业 | 已经开展的实践、过程调整和可追溯结果 | 最近一次真实运营中，你们改了什么，前后怎样比较？ |

演讲看回答是否切题、证据是否清楚、分工能否承接追问；文案看材料之间的口径、结构与证据可定位性。视觉华丽或口号响亮不能代替以上内容。

## 从材料找两条薄弱链，每次只问一个问题

以下是教练设计的候选链，不是往届评委原话。先引用户的页码或原题号，提第一问，再根据回答决定是否继续；不可整条连问。回答充分就认可并切换。

| 材料触发点 | 首问 | 回答后可继续下钻 |
| --- | --- | --- |
| “电商平台”，只有APP功能图 | 请用一笔真实或明确标为设想的交易说明，谁向谁付费？ | 获客入口→下单与履约→结算→售后；使用者与付费者是否同一方 |
| “需求旺盛”，只有宏观市场规模 | 哪条一手调研记录直接改变了你的方案？ | 对象与时间→原需求→团队调整→试用/成交证据；不把意向当付款 |
| “销售额增长”，只给一个大数 | 这个数是下单额、支付额，还是扣除退款后的结算额？ | 周期与渠道→退款口径→自然/付费流量→利润；GMV不等于团队收入 |
| “成本低、利润高” | 这笔订单扣除履约和获客支出后，还剩多少？ | 采购、包装、物流、佣金、退货、广告、人工；缺账目就保留证据缺口 |
| “精准营销、转化提升” | 转化率的分母是什么？ | 曝光/点击/访客→去重与归因→同周期对照→补贴和活动影响 |
| “AI赋能” | AI具体替代或改善了运营中的哪个动作？ | 原流程→人机分工→错误处理→同条件效果；使用现成模型不冒称自研模型 |
| “带农增收、社会价值” | 增收对应的是哪些对象、哪个周期、哪种收入口径？ | 团队新增贡献→成本扣除→受益记录；不挪用合作企业全量业绩 |
| “跨境、全球市场” | 你们首先服务哪个地区、哪类买家？ | 渠道、当地需求、物流退货、支付汇率、真实履约；不凭一般常识保证合规 |
| “实战成绩优秀” | 哪份平台或合作方记录能对应这项成绩？ | 账号/统计周期→准备和过程留痕→本人动作→成绩；不把截图当完整审计 |
| “团队分工明确” | 请选一项关键运营调整，说清谁作出判断、谁执行、怎样验证。 | 团队与导师/企业贡献分别说明；不按头衔推断贡献 |

商务大数据项目：追问数据来源、抽样与清洗、指标口径、验证方式、建议怎样落到业务决策，不要求每个项目都有直接销售收入。实战赛的具体指标以当届专项文件为准；没有该文件时先按通用运营证据训练并标记规则待补。

## 八分钟讲述建议（教练建议，不是官方分段要求）

总目标约7分30秒，留30秒余量：需求与调研60秒；产品/服务与创新90秒；业务和营销方案90秒；实践过程与结果120秒；团队、财务与下一步90秒。按真正成立的优势调整篇幅，不平均展示、不为适配段落编故事。

每个关键段至少能落到一条“主张—自己的行动—证据—价值”。产品展示要说明用户完成了什么任务；讲市场须接到第一批客户；谈增长同时讲口径；讲下一步必须与当前可用资源衔接。参考视频的节奏，不搬用其他团队的数字、客户或亲历经历。

## 回答与复盘

优先“直接判断→一个自己的证据→对业务的意义→必要边界”，根据问题取用，不机械念四步。例如可生成填空练习：

> 我们首先解决的是【已核实对象】在【具体环节】的问题。根据【本项目记录及周期】，我们做了【本人/团队动作】，观察到【已有结果】。因此目前可以证明【价值范围】；【未验证部分】还需要【补证动作】。

空缺必须保留，不能替学生填入虚构结果。没有完整核算仍可以讲已证实的运营改进，不主动夸大，也不以“暂未盈利”否定一切创新。

逐题报告绑定Q号与P页；非言语只引用采集到的事件。最终按本轮5/7项给强/中/弱/缺失及依据，未覆盖写明。三项当晚可练的动作从具体问题选：把GMV与营收分开重答两遍；用45秒讲清一笔交易；打开自己的证据页后再报告数字。需要新增订单或调研的事项另列证据补充，不冒充一晚可完成的表达训练。
